Порядок появления: концепция → спецификация (проверена по концепции) → план (проверен по спецификации) → реализация. Идентификаторы требований (`RSP-01`, `PRO-10`…) связывают спецификацию, план и тесты: `scripts/trace.sh` показывает, какие требования покрыты.
